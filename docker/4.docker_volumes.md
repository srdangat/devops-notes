# Docker Volumes

Docker containers are **ephemeral** by default.

When a container is removed:
- Its writable layer is deleted
- All stored data inside it is lost

To persist data, Docker provides **Volumes**.

---

# What Are Docker Volumes?

## Docker volumes:

- Are managed by Docker
- Exist outside the container filesystem
- Survive container removal
- Can be reused by multiple containers
- Are recommended for databases and production workloads

---

# Volume Commands

## Create a Volume

```bash
docker volume create my-volume
```

## List Volumes

```bash
docker volume ls
```

## Inspect a Volume

```bash
docker volume inspect my-volume
```

## Remove a Volume

```bash
docker volume rm my-volume
```


Example: MySQL with Persistent Storage

`Create a volume`
```bash
docker volume create db-data
```

`Run MySQL container using the volume`

```bash
docker run -d \
  --name sql-db \
  -e MYSQL_ROOT_PASSWORD=test@123 \
  -v db-data:/var/lib/mysql \
  -p 3306:3306 \
  mysql
```

`Test persistence`
Connect to PostgreSQL and create a database:

```bash
docker exec -it sql-db mysql -u root -p
CREATE DATABASE myapp;
```

`Stop and remove the container:`
```bash
docker stop sql-db && docker rm sql-db
```
`Recreate it using the same volume:`

```bash
docker run -d \
  --name db \
  -e MYSQL_ROOT_PASSWORD=test@123 \
  -v db-data:/var/lib/mysql \
  -p 3306:3306 \
  mysql
```
The myapp database will still exist because the data is stored in the volume.

## Bind Mounts
What Are Bind Mounts?

Bind mounts map a host directory or file into a container.

They:

- Are not managed by Docker
- Depend on host filesystem structure
- Commonly used in development

Example: Nginx with Bind Mount

`Create a project folder`
```bash
mkdir my-website
cd my-website
```
`Create an index file`
```bash
echo "<h1>Hello from Bind Mount</h1>" > index.html
```
`Run Nginx with bind mount`
```bash
docker run -d \
  --name nginx-dev \
  -p 8080:80 \
  -v $(pwd):/usr/share/nginx/html \
  nginx
```
Now Open 
```bash
http://localhost:8080
```
`Edit index.html`

Refresh browser

Changes appear instantly without rebuilding the container.


# Volumes vs Bind Mounts

| Feature              | Volumes | Bind Mounts |
|----------------------|---------|-------------|
| Managed by Docker    | Yes     | No          |
| Production Ready     | Yes     | Limited     |
| Host Dependency      | No      | Yes         |
| Best for Databases   | Yes     | No          |
