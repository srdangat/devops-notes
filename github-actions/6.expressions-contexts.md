# GitHub Actions: Expressions & Contexts

---

**Expressions** let you dynamically compute values inside workflows using the `${{ }}` syntax. **Contexts** are objects that provide information about the workflow run, repository, runner, and more.

---

## 1. Expression Syntax

- Expressions are written as `${{ <expression> }}`.
- Used in `run:`, `env:`, `if:`, and other fields.
- Can contain **contexts**, **functions**, **operators**, and **literals**.

```yaml
- name: Print branch
  run: echo "Branch is ${{ github.ref_name }}"
```

---

## 2. Common Contexts

### `github` — Info about the workflow run and repository

| Expression | Description |
|---|---|
| `${{ github.ref_name }}` | Branch or tag name (`main`, `feature-x`) |
| `${{ github.sha }}` | Commit SHA |
| `${{ github.actor }}` | Username that triggered the workflow |
| `${{ github.repository }}` | `owner/repo` |
| `${{ github.event_name }}` | Event that triggered the workflow (`push`, `pull_request`) |
| `${{ github.run_id }}` | Unique ID for the workflow run |

### `runner` — Info about the runner machine

| Expression | Description |
|---|---|
| `${{ runner.os }}` | OS name (`Linux`, `Windows`, `macOS`) |
| `${{ runner.arch }}` | Architecture (`X64`, `ARM64`) |
| `${{ runner.temp }}` | Path to temp directory |

### `env` — Access workflow/job/step environment variables

```yaml
env:
  MY_VAR: hello

steps:
  - run: echo "${{ env.MY_VAR }}"
```

### `secrets` — Access repository secrets

```yaml
- run: echo "Token length: ${{ secrets.API_TOKEN }}"
```

### `steps` — Access outputs from previous steps

```yaml
steps:
  - name: Set value
    id: my_step
    run: echo "result=42" >> $GITHUB_OUTPUT

  - name: Use value
    run: echo "Result is ${{ steps.my_step.outputs.result }}"
```

---

## 3. Conditional Expressions (`if:`)

- Use `if:` to **conditionally run or skip** a step/job.
- The `${{ }}` wrapper is **optional** inside `if:`.

```yaml
# Run only on main branch
- name: Deploy
  if: github.ref_name == 'main'
  run: ./deploy.sh

# Run only on push events
- name: Build
  if: github.event_name == 'push'
  run: ./build.sh

# Run only if previous step failed
- name: Notify on failure
  if: failure()
  run: echo "Something went wrong!"
```

---

## 4. Useful Built-in Functions

| Function | Description |
|---|---|
| `success()` | Returns true if all previous steps passed |
| `failure()` | Returns true if any previous step failed |
| `always()` | Always runs the step, regardless of outcome |
| `contains(str, substr)` | Checks if string contains substring |
| `startsWith(str, prefix)` | Checks if string starts with prefix |
| `toJSON(value)` | Converts a value to JSON string |

```yaml
- name: Always clean up
  if: always()
  run: rm -rf temp/

- name: Check branch name
  if: startsWith(github.ref_name, 'release')
  run: echo "This is a release branch"
```

---

## Key Rules

- Use `${{ }}` syntax everywhere **except** inside `if:` (optional there).
- Contexts are **read-only** — you cannot modify them directly.
- To pass data between steps, use `$GITHUB_OUTPUT` (not environment variables).
- Use `toJSON()` to debug contexts: `run: echo '${{ toJSON(github) }}'`
